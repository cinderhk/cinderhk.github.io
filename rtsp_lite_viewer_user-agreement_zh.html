本协议适用于您使用 RTSP Lite Viewer 的行为。本应用由其应用商店页面所列的开发者提供（以下简称“我们”）。使用本应用前，请阅读本协议和隐私政策。

1. 关于本应用

RTSP Lite Viewer 用于连接您有权访问的摄像头和媒体服务。功能包括视频播放、ONVIF 手动连接、通过外部 GB28181 网关获取播放地址、多摄像头画面、截图、录像、本地回放、分享，以及配置导入和导出。

我们不提供摄像头硬件、公共视频资源库或由开发者运营的云端录像服务。您需要自行提供设备、连接信息、凭据和网络。功能是否可用取决于设备兼容性、媒体格式、权限和网络状况。

2. 合法授权使用

请仅将本应用用于您拥有或获准访问的设备和内容。在查看、录制或分享他人的影像、声音或个人信息前，请履行必要的告知义务，并取得所需的许可或同意。

您不得使用本应用实施以下行为：

  • 未经授权访问摄像头或网络、窃取凭据或绕过访问控制。
  • 实施非法监视、跟踪、骚扰或其他侵犯隐私的行为。
  • 未经许可复制、分发受保护的内容，或绕过数字版权保护措施。

您依法拥有的内容权利仍归您所有。使用本应用不代表您授权我们将摄像头内容用于广告、公开展示或人工智能训练。未成年人应在适当监护下使用本应用，并在法律要求时取得监护人同意。

3. 您的数据与文件

摄像头设置和凭据使用系统安全存储。除非您主动导出或分享，已保存的截图和录像保存在应用私有存储空间内。详情请参阅隐私政策。

导出的配置 JSON 文件未单独加密，其中包含已保存的密码、带有凭据的 URL 和网关鉴权信息。请妥善保护这些文件，仅导入可信配置，并谨慎选择导出位置。

删除应用数据或恢复出厂设置不会删除相册、云存储、其他应用或外部摄像头服务中的副本。恢复出厂设置会清除本地应用数据，包括协议同意记录，并返回首次启动的协议确认页面。删除重要内容前，请先备份。

4. 外部服务与费用

本应用会连接您配置的摄像头、ONVIF 服务、网关以及这些服务返回的媒体地址。相关服务提供方有各自的条款和隐私处理规则。您分享的文件由您选择的接收方处理。

RTSP、RTMP 或 HTTP 等连接可能不加密。在支持的情况下，请使用 HTTPS、RTSPS 或可信的安全网络，并保护好您的凭据。

本版本没有应用内购买或自动续订订阅。任何下载价格均以应用商店展示为准。网络、硬件和外部服务的费用由相应提供方确定。App Store 购买和退款申请适用 Apple 的流程及相关消费者权益规定。
